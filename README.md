# Photo+api

A React photo gallery web application built with Vite and Tailwind CSS.

## Features

- **Photo Feed**: Fetches and renders photos from the Lorem Picsum API.
- **Search by Author**: Real-time client-side search filtering by photographer name.
- **Favourites Management**: Add or remove photos from favourites using `useReducer`, persisted across sessions in `localStorage`.
- **Loading & Error States**: Responsive feedback during data fetching.

## Tech Stack

- **React 19**
- **Tailwind CSS v4**
- **Vite**
